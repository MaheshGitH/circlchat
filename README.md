## 🛠️ Tech Stack

- Next.js
- Tailwind CSS
- MongoDB
- Auth.js
- Socket.io
- Figma (UI Design)

## ✨ Features

- Authentication (Google, GitHub, Magic Link)
- Real-time group chat using Socket.IO
- Group creation and joining
- MongoDB integration for storing user and group data
- UI using Tailwind CSS
